## 📌 Overview

A footwear and sneaker brand e-commerce storefront. Designed with dynamic 360-degree image switching, interactive shoe size selector, color swatch toggling, and add-to-bag animation.

---

## ✨ Key Features

- **Interactive Color Swatch Switcher:** Dynamically change sneaker colors and primary product image in real time.
- **Size Selection Matrix:** Visual shoe size picker with instant availability feedback.
- **Product Feature Accents:** Highlights cushioning technology, sole grip, and breathable mesh benefits.
- **Smooth Shopping Cart Feedback:** Interactive cart badge update on item purchase.

---

## 💻 Tech Stack & Architecture

- **Technologies:** Semantic HTML5, CSS3 Transitions, Vanilla JavaScript DOM

# 2. Navigate into project directory

# Simply open index.html in your preferred browser
